# Segurança e dados privados

Currículos, configurações reais, histórico, SQLite e armazenamento do navegador ficam fora do Git. Sessões dão acesso à conta: não compartilhe `.local-jobs/`, nem em issues ou anexos.

O projeto começa com envio desativado. Perguntas desconhecidas não devem receber respostas inventadas. Não contorne CAPTCHA, login, restrições de origem ou avisos de segurança para enviar candidaturas.

Remova dados pessoais de logs e telas antes de reportar erros. Se uma sessão for publicada, revogue o acesso e remova os dados do histórico remoto. Adicionar ao .gitignore depois de versionar não remove o arquivo dos commits anteriores.
