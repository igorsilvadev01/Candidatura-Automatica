# Avisos de terceiros

O framework de origem é ai-job-search, Copyright (c) 2026 Mads Lorentzen, sob licença MIT. A licença foi preservada em LICENSE. O contrato de consulta Freehire foi adaptado do CLI daquele framework.

O runtime usa Playwright, python-jobspy, Beautiful Soup e dependências. As versões resolvidas na instalação de origem estão em tools/local_jobs/requirements.lock.txt. As bibliotecas não são vendorizadas; suas licenças acompanham os pacotes instalados.

Este projeto é independente de Gupy, Indeed, Freehire e Google. Um adaptador não implica afiliação ou garantia de acesso.
